# Visión del producto — Pet ID

Pet ID es una plataforma de identidad digital para mascotas conectada con placas físicas (QR + NFC pasivo).

## Propuesta de valor

Una persona encuentra una mascota → escanea QR/NFC → ve información autorizada → puede llamar, WhatsApp o reportar hallazgo → el propietario recibe aviso.

## Fuera de alcance MVP

GPS, Bluetooth, app móvil nativa, expediente clínico completo, API pública, pagos (fase posterior).

## Mercado inicial

México — español, MXN, zona horaria `America/Mexico_City`.
