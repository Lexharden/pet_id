# Glosario de dominio

| Término | Definición |
|---------|------------|
| **Placa (Tag)** | Producto físico con QR/NFC; entidad independiente de la mascota |
| **Token público** | Identificador aleatorio en URL `/t/{token}`; no es el ID de BD |
| **Código de activación** | Secreto de un solo uso para vincular placa a mascota; almacenado hasheado |
| **Asignación** | Relación histórica placa ↔ mascota |
| **Perfil público** | Vista móvil sin login con datos autorizados por el propietario |
| **Resumen de emergencia** | Info médica crítica opcionalmente visible (no expediente clínico) |
| **Escaneo** | Evento de lectura de placa; datos minimizados |
| **Modo perdida** | Estado que destaca banner y habilita formulario de hallazgo |
